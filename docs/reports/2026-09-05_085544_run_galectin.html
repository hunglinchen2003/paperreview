2. B細胞急性淋巴母細胞白血病中 T 細胞耗竭與 Galectin‑9 介導的免疫抑制（Galectin‑9 作為 TIM‑3 配體在 Blinatumomab 失效中的免疫抑制作用）

核心機制：Galectin‑9 作為 TIM‑3 配體，透過與 CD8+ T 細胞表面 TIM‑3 受體結合，誘導 T 細胞耗竭並抑制其細胞毒性功能。基因 ZNF683 的低表達削弱了 TEM 的細胞毒性程式化，使得即使在激活狀態下也無法有效殺傷腫瘤細胞。 實驗亮點：結合流式、單細胞 CITE‑seq 及血清蛋白質組學，首次將基線 T 細胞表型與治療後耗竭程度直接關聯；利用體外 Blina 培養系統量化細胞毒性喪失。 臨床啟示：可在治療前透過 ZNF683 表達水平或 TEM 亞群比例進行風險分層，並考慮加入 Galectin‑9/TIM‑3 抑制劑或 M2‑極化因子拮抗劑以提升 Blina 效果。

3. Galectin‑3 相分離與非典型分泌（由糖蛋白誘導的相分離機制驅動 Galectin‑3 的非傳統分泌）

  • 核心機制：糖蛋白結合 Galectin‑3 的 S 面，解除 N‑端尾部的抑制，使其相分離並凝聚成大顆粒；這些凝聚物再招募 ALG‑2，將其定位於 ER–晚期內涵體界面，最終透過 SNARE 介導的囊泡輸送被釋放到細胞外。
  • 實驗亮點：
- 四種不同的溶酶體損傷模型（如化學、物理或基因誘導）均能重現 Galectin‑3 的快速釋放，證明機制普遍性。 - 在體外相分離實驗中使用純化蛋白與糖蛋白混合，直接觀察到 Galectin‑3 的凝聚與 N‑端尾部解開；利用突變體確認 S 面結合位點的重要性。 - 利用免疫共沉澱和高解析度顯微鏡證實 ALG‑2 與 Galectin‑3 凝聚物的互作，並追蹤其在 ER–晚期內涵體界面的定位。
  • 臨床啟示：此機制可能是細胞對膜損傷的一種清除反應；若能調控 Galectin‑3 的相分離與釋放，可作為治療腫瘤免疫逃逸、炎症或自體免疫疾病的新策略。

4. Galectin‑1 在腎小球血管炎中的角色（免疫調節、血管通透性與腎小球內皮細胞黏附蛋白（整合素β5）及CAVN1磷酸化的關聯）

  • 核心機制：Galectin‑1 透過調節整合素β5 表達與 CAVN1 磷酸化，影響內皮細胞黏附與 caveolae 結構，進而改變血管通透性。<br>- 實驗亮點：結合基因沉默、IFNγ 刺激及全譜蛋白質/磷酸化分析，首次揭示 Galectin‑1 在 ABMR 中的多層次調控；微流控模型證明缺失 Galectin‑1 時血管通透性升高且促炎細胞因子分泌增加。<br>- 臨床啟示：Galectin‑1 可能成為 ABMR 的生物標記或治療靶點；調節其表達或功能可潛在減緩腎移植後的血管炎症與慢性損傷。

5. Galectin‑3 為心衰新發指標（Galectin-3 在心衰發生風險中的預測價值與機制探討）

核心機制：Galectin‑3 介導心肌纖維化、炎症反應及氧化壓力，促進心肌重塑與功能衰退。 實驗亮點：本研究通過荊棘圖統計顯示 Gal-3 的 HR 為 1.23，表明其獨立於其他標記的預測價值；同時納入多種心衰表型與性別子組分析，證實其普遍適用性。 臨床啟示：Gal-3 可作為早期篩查工具，協助識別高風險人群，並可能成為靶向治療的潛在標靶；然而需進一步驗證其對治療決策影響。
