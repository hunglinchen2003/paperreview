In Bash you don’t need the `-` operator to build a list of numbers – you can let the shell do it for you.  
The most common and “Bash‑ish” ways are:

```bash
# 1. Brace expansion (fast, no external command)
for i in {1..10}; do
    echo "$i"
done

# 2. C‑style arithmetic loop (more flexible, works with variables)
for ((i=1; i<=10; i++)); do
    echo "$i"
done
```

If you need to use the `-` operator inside the loop (e.g., to get the previous value), just do it in the arithmetic expansion:

```bash
for ((i=1; i<=10; i++)); do
    prev=$((i-1))
    echo "current=$i  previous=$prev"
done
```

So the “best” way is to use brace expansion or a C‑style loop; the `-` operator is only used for arithmetic inside the loop, not for generating the range itself.
